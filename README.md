# PurOriginals Tech Showcase 👟

> **Nota:** este repositorio es una versión de portafolio, creada a partir de un proyecto real en producción (PurOriginals, tienda de sneakers Adidas en Bogotá). No contiene precios, inventario, backups, credenciales ni datos de clientes reales. El objetivo es mostrar el trabajo técnico realizado, no el negocio en sí.

## 📌 Sobre el proyecto

PurOriginals es mi negocio de reventa de tenis Adidas originales. Además de operarlo, lo usé como caso real para aprender y aplicar automatización, IA e integración de sistemas: un dashboard de gestión, funciones serverless, scripts de automatización de catálogo/inventario y un chatbot de WhatsApp Business para atención al cliente y agendamiento de citas.

Todo lo que se describe aquí está funcionando en producción, no es un ejercicio de práctica ni un tutorial seguido paso a paso.

## 🎓 Sobre mí

Soy Johan (PurOriginals), colombiano, bilingüe español-inglés. Mi formación técnica es un título técnico en Programación de Software del SENA. El resto de las herramientas de este proyecto (automatización con IA, integraciones, serverless) las aprendí de forma autodidacta, aplicándolas directamente a mi propio negocio para resolver problemas reales de operación.

Actualmente busco posiciones de soporte técnico / atención al cliente bilingüe (BPO), donde pueda combinar mi experiencia como agente y coach en call center con estas habilidades técnicas.

## 🛠️ Stack tecnológico

- **Automatización con IA:** Claude, Claude Code y Claude Cowork, usados para gestionar catálogo, inventario y flujos de atención al cliente.
- **Chatbots y automatización de flujos:** n8n, integrado con WhatsApp Business para atención de marca y agendamiento de citas.
- **Backend / Serverless:** funciones serverless desplegadas en Netlify.
- **Base de datos y lógica de negocio:** SQL, PHP, entornos de desarrollo local WAMP/XAMPP.
- **Scripting y automatización:** PowerShell y Python para carga y migración de datos de catálogo/inventario.
- **Otros lenguajes con los que tengo nociones:** Python, Java (formación SENA).
- **Control de versiones:** Git y GitHub.

## ⚙️ Funcionalidades clave

- **Dashboard de gestión:** panel para visualizar y administrar el catálogo de productos y su estado.
- **Funciones serverless (Netlify):** lógica de backend desacoplada del frontend, desplegada sin servidor propio.
- **Automatización de catálogo e inventario:** scripts para cargar, migrar y actualizar información de productos de forma masiva, reduciendo el trabajo manual repetitivo.
- **Chatbot de WhatsApp Business (n8n):** atención a clientes y agendamiento de citas de forma automatizada, integrando IA para respuestas más naturales.
- **Flujo de trabajo asistido por IA:** uso de Claude Code/Cowork como copiloto para tareas de desarrollo, documentación y mantenimiento del proyecto.
