# PurOriginals Tech Showcase 👟

> **Note:** this repository is a portfolio version built from a real, live project (PurOriginals, an Adidas sneaker reselling business in Bogotá, Colombia). It contains no real prices, inventory, backups, credentials, or customer data. The goal is to showcase the technical work, not the business itself.

## 📌 About the project

PurOriginals is my sneaker reselling business. Beyond running it day to day, I used it as a real-world case to learn and apply automation, AI, and systems integration: a management dashboard, serverless functions, catalog/inventory automation scripts, and a WhatsApp Business chatbot for customer service and appointment scheduling.

Everything described here is running in production — this is not a tutorial exercise or a practice project.

## 🛠️ Tech stack

- **AI automation:** Claude, Claude Code, and Claude Cowork, used to manage catalog, inventory, and customer service workflows.
- **Chatbots and workflow automation:** n8n, integrated with WhatsApp Business for brand support and appointment scheduling.
- **Backend / Serverless:** serverless functions deployed on Netlify.
- **Database and business logic:** SQL, PHP, local development environments (WAMP/XAMPP).
- **Scripting and automation:** PowerShell and Python for catalog/inventory data loading and migration.
- **Other languages with basic proficiency:** Python, Java (SENA training).
- **Version control:** Git and GitHub.

## ⚙️ Key features

- **Management dashboard:** panel to view and manage the product catalog and its status.
- **Serverless functions (Netlify):** backend logic decoupled from the frontend, deployed without a dedicated server.
- **Catalog and inventory automation:** scripts to bulk-load, migrate, and update product data, cutting down repetitive manual work.
- **WhatsApp Business chatbot (n8n):** automated customer service and appointment scheduling, with AI-assisted responses for a more natural conversation.
- **AI-assisted workflow:** using Claude Code/Cowork as a copilot for development, documentation, and maintenance tasks.
